# Windows 10X OS Simulator **(emulator)**!

## Что такое Win 10X

Windows 10X Emulator (то есть **симулятор**) - это симулятор ОС пропавшей и закрытой системе ![Windows 10X](https://ru.wikipedia.org/wiki/Windows_10X) которая разработана компанией Microsoft. 
Изначально они хотели сделать систему для двухэкраных планшетов Microsoft Surface. Операционая система является недоделаной и она была в бета-версии для тестирования. Майкрасофт (компания-создатель) решила
доделать систему и превратила ее в ![Windows 11](https://ru.wikipedia.org/wiki/Windows_11) которая имеет похожий интерфейс, норм поддержку драйверов и более безопасная работа и меньше количество дыр в безопасности. И вот я вдохновился Win 10X и решил ее написать на C#.
Мой эмулятор пока что в разработке и если вы заметили баг или хотите мне помочь то напишите мне в Issues. Рад помочь!
